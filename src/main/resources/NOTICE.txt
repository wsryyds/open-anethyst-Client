        Copyright (c) 2017 tterrag. License: MIT.
        Full text: licenses/BLUR-MIT.txt
        Note: MODIFIED -- the fragment shader (fade_in_blur.fsh) and the four-pass

（含 net.client.replay.* 回放子系统）均为本项目自行编写；回放子系统不含
ReplayMod 代码。唯一的第三方代码是背景模糊实现 net.client.util.BackdropBlurPipeline，
其着色器与 pass 流程移植自 Blur（MIT，见第 3 项）。
jar 内只包含：
  1) 本项目自行编写的代码与素材（含 assets/client、assets/md3 下的界面素材）；
  2) 第 1 项第三方组件（JNA，Apache-2.0，以嵌套 jar 形式分发）；
  3) 第 2 项 McPacks / FastPacks 移植代码（MIT）；
  4) 第 3 项 Blur 背景模糊着色器的移植代码（MIT）；
  5) 第 4 项 Roboto / Material Icons 字体与图标（Apache-2.0）；
  6) 第 5 项 Noto 字形图集（OFL-1.1，仅构建期栅格化后的图集）。
除此之外不再分发任何其它内容：不内嵌任何字体资源包（高清字体功能已移除），
也不含 ReplayMod 或其它客户端/模组的代码。回放子系统与 MD3 界面套件均为本项目
为本客户端自研，从未作为独立项目以任何开源许可对外发布。

【English】All Java source code under net.client and net.client.ui.md3 in this project (including the
replay subsystem net.client.replay.*) was written for this project. No source
code from any other Minecraft mod or client was copied into this project, and the
replay subsystem contains no ReplayMod code.
The jar contains only:
  1) code and assets created for this project (including the UI assets under
     assets/client and assets/md3);
  2) the third-party component listed in item 1 above (JNA, Apache-2.0, shipped as
     a nested jar);
  3) the McPacks / FastPacks port in item 2 (MIT);
  4) the Roboto / Material Icons fonts and icons in item 3 (Apache-2.0);
